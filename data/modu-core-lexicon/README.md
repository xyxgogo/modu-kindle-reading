# 墨读核心词汇库 v1

本目录保存墨读 v2 运行所需的核心 500 词正式数据和来源登记。可执行的 D1/SQLite 种子位于 `drizzle/0005_seed_modu_core_500.sql`，Postgres 版本位于 `db/postgres/0002_seed_modu_core_500.sql`。

基础词频顺序部分基于 New General Service List (NGSL) 1.2：Browne, C., Culligan, B. & Phillips, J., *The New General Service List*。NGSL 内容采用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；来源数据与墨读自编中文释义、例句及学习内容分层保存。

项目代码继续使用仓库根目录的 MIT License；词库数据遵循各自 `source_registry.json` 所列来源和许可。不得把 Oxford、Cambridge、Collins、Longman、有道等商业词典内容直接批量复制进本词库。

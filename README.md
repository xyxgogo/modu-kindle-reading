墨读 · Kindle 家庭阅读与单词学习站

## 把闲置 Kindle，变成一台阅读神器和英语学习宝库

家里那台已经很少使用、却依然能亮屏的旧 Kindle，不一定要躺在抽屉里吃灰。墨读提供了一种简单而实用的废旧 Kindle 再利用选择：无需安装复杂应用，也不依赖花哨的前端动画，就能把它重新变成一台专注、护眼、适合长期使用的家庭阅读器和英语学习设备。

墨读面向 Kindle 旧版浏览器设计，页面轻量、操作直接，围绕“少打扰地读、持续地学”展开。家长可以为孩子准备读物和学习内容，孩子则可以在熟悉的墨水屏上阅读、复习和完成单词考核。

正式站点：<https://modu.1005205.xyz>

## 你可以用墨读做什么

### 让旧 Kindle 重新派上用场

- 把闲置设备变成专注阅读终端，减少手机和平板带来的通知干扰。
- 采用服务端生成页面，不依赖前端 JavaScript，兼顾老 Kindle 浏览器的兼容性。
- 黑白、高对比、清晰大字和简洁导航，更贴合墨水屏的阅读习惯。

### 为家庭阅读建立一个小而可靠的空间

- 孩子：注册后使用“阅读”和“单词”模块。
- 家长：申请并经管理员审核后，可发布读物、管理单词范围、绑定孩子或学生。
- 管理员：审核家长申请和读物上架，并管理考核内容。
- 家长与孩子/学生通过 ID 绑定，绑定后不可随意更改，关系清晰、使用稳定。
- 孩子只能访问已绑定家长发布且经管理员审核通过的读物和考核内容。

### 让英语学习更适合 Kindle

- 阅读页支持四档字体大小：标准、大、加大、加加大，照顾不同年龄和视力需求。
- 支持分页阅读、目录、上一页/下一页和个人主页等 Kindle 友好导航。
- 单词考核采用选择类题型，主动避开需要 Kindle 输入法输入的题目。
- 预留管理员扩展考核范围和考核方式的能力，逐步形成可复用的学习内容库。

## 适合谁

- 想让旧 Kindle 继续发挥价值的人
- 希望减少孩子屏幕娱乐干扰、保留阅读专注感的家庭
- 想把阅读和英语学习放在同一台轻量设备上的家长
- 喜欢自己搭建、自己维护家庭学习工具的开发者

## 技术结构

- Node.js 服务端渲染
- SQLite 数据库
- Netlify Functions
- Netlify Blobs 持久化数据库快照和上传文件
